# Sales Performance Dashboard

An executive sales dashboard built in **Power BI** for tracking revenue, profit, and year-over-year growth.

## What it does

- Tracks **revenue**, **profit**, and **YoY growth** at a glance for leadership review
- **DAX measures** power the core KPIs and time-intelligence calculations
- **Dynamic visuals** — slicers and interactions let stakeholders explore the numbers themselves

## Tech stack

- **Power BI** — data modeling, DAX measures, interactive visuals
- **Excel / Power Query** — data cleaning and preparation

## Key questions it answers

- How are revenue and profit trending over time?
- Is growth accelerating or stalling year over year?
- Which areas need attention this quarter?
